# Savannah Tracing UI Standards v1.0

## Page shell
- Desktop maximum content width: 1180px.
- Reading / legal content maximum width: 760-820px.
- Desktop horizontal gutter: 24px.
- Tablet horizontal gutter: 20px.
- Mobile horizontal gutter: 16px.
- Standard section spacing: 64-72px desktop, 48-54px tablet, 36-44px mobile.

## Responsive breakpoints
- Desktop: > 850px.
- Tablet: 521-850px.
- Mobile: <= 520px.
- No horizontal scrolling on public pages.
- Primary actions become full-width on mobile where appropriate.

## Brand
- Use only the transparent Savannah logo asset.
- Header logo: 190x62 desktop, 170x56 tablet, 150x50 mobile.
- Footer logo: 190x64 desktop, 165x56 mobile.
- Always object-fit: contain. Never stretch, recolour, invert, or place the cream-background legacy logo.

## Typography
- System font stack: Inter, system-ui, -apple-system, Segoe UI, Roboto, Arial, sans-serif.
- Page titles: 34-56px responsive.
- Section titles: 28-42px responsive.
- Eyebrows: 11-12px, uppercase, 0.16em tracking.
- Body: 14-19px based on context, minimum 14px for operational UI.
- Button text: 14px standard, 750 weight.

## Buttons and fields
- Standard control height: minimum 48px desktop/tablet, 50px mobile primary actions.
- Standard button radius: pill.
- Standard field radius: 12px.
- Standard card radius: 20px.
- Avoid mismatched font size, weight or height between primary and secondary CTAs.

## Modals
- Standard modal: 820px max width.
- Small modal: 520px max width.
- Large workflow modal: 1040px max width.
- Desktop viewport margin: 20px minimum.
- Mobile viewport margin: 8px.
- Mobile modal radius: 18px.
- Modal actions may remain sticky on mobile for long forms.
- Modal must open at the top of its content.

## Notifications
Four canonical notification types:
1. Info — neutral guidance or process status.
2. Success — confirmed completed action.
3. Warning — action needed or non-blocking issue.
4. Error — failed or blocked action.

- Inline notices use 14px radius and 13px text.
- Toast stack appears top-right desktop and full-width inset on mobile.
- Never communicate status using colour alone; always include text.
- Success messages state what happened and the next step.
- Error messages state what failed and what the user can do next.

## Cards
- Border: 1px neutral line.
- Radius: 20px.
- Use subtle shadows only.
- Do not mix unrelated card radii or padding within the same page.

## Commercial product naming
- Savannah Institutional
- Savannah BenefitWatch
- Savannah Recovery Services

## Customer lifecycle language
- Lead: application submitted, not yet onboarded.
- Onboarding: banking / mandate / verification process underway.
- Client: final onboarding complete and membership activated.
- Test records never count as leads, onboarding customers or clients.

## Rule
All new Savannah public pages, internal Savannah modules, modals, forms and notifications must use these standards unless a documented product reason requires an exception.
